# gif-reframe

一個簡單的 GIF 幀數重新取樣工具，可以將 GIF 動畫統一轉換成指定的幀數。

## 功能特色

- 🎯 將多個 GIF 統一轉換成指定幀數
- 🎨 使用高品質調色盤保持畫質
- ⚙️ 支援 JSON 設定檔自訂參數
- ✅ 內建幀數檢查工具
- 📁 可自訂輸出資料夾名稱

## 系統需求

### 必要套件

1. **FFmpeg**
   - 下載：https://www.gyan.dev/ffmpeg/builds/
   - 選擇 `ffmpeg-release-essentials.zip`
   - 解壓縮後將 `bin` 資料夾加入系統環境變數 PATH

2. **驗證安裝**
```bash
   ffmpeg -version
   ffprobe -version
```
   如果能正常顯示版本資訊，代表安裝成功

## 檔案說明
```
GIFResampler/
├── process.bat          # 主處理程式
├── check.bat           # 幀數檢查程式
├── config.json         # 設定檔
├── README.md           # 說明文件
├── *.gif              # 要處理的 GIF 檔案（放這裡）
└── outputs_XXf/       # 輸出資料夾（自動建立）
```

## 使用方式

### 1. 設定參數

編輯 `config.json` 檔案：
```json
{
  "frame": 20,
  "output": "my_output"
}
```

**參數說明：**
- `frame`：目標幀數（必填，例如：15、20、30）
- `output`：輸出資料夾名稱（選填）
  - 如果未指定，預設為 `outputs_20f`（根據幀數自動命名）

**範例設定：**
```json
{
  "frame": 15
}
```
→ 輸出到 `outputs_15f/`
```json
{
  "frame": 20,
  "output": "final_gifs"
}
```
→ 輸出到 `final_gifs/`

### 2. 處理 GIF

1. 將要處理的 GIF 檔案放在與 `run.bat` 同一層目錄
2. 雙擊執行 `run.bat`
3. 等待處理完成
4. 處理後的檔案會輸出到指定的資料夾

**輸出檔名格式：**
- 原檔名：`example.gif`
- 輸出檔名：`example_20f.gif`（會加上幀數標記）

### 3. 檢查結果

執行 `check.bat` 來驗證輸出的 GIF 是否符合目標幀數：
```
檢查 outputs_20f 資料夾中的 GIF 是否為 20 幀...

[OK] example_20f.gif - 20 幀
[OK] test_20f.gif - 20 幀
[NG] broken_20f.gif - 18 幀 (應該是 20 幀)

======================================
總共檢查: 3 個檔案
正確(20幀): 2 個
不正確: 1 個
======================================
```

## 使用範例

### 範例 1：基本使用
```json
{
  "frame": 20
}
```

1. 放入 3 個 GIF：`cat.gif`、`dog.gif`、`bird.gif`
2. 執行 `process.bat`
3. 輸出到 `outputs_20f/`：
   - `cat_20f.gif`（20 幀）
   - `dog_20f.gif`（20 幀）
   - `bird_20f.gif`（20 幀）

### 範例 2：自訂輸出資料夾
```json
{
  "frame": 15,
  "output": "web_assets"
}
```

1. 執行後輸出到 `web_assets/` 資料夾
2. 每個 GIF 都是 15 幀

### 範例 3：高幀數轉換
```json
{
  "frame": 30,
  "output": "smooth_30fps"
}
```

適合需要更流暢動畫的場景

## 常見問題

### Q: 為什麼執行後沒有反應？
A: 請確認：
1. FFmpeg 已正確安裝並加入 PATH
2. 當前目錄有 `.gif` 檔案
3. 執行時以系統管理員身份執行

### Q: 處理後檔案很大怎麼辦？
A: 本工具使用高品質調色盤，檔案會比較大。如需壓縮可以：
- 降低目標幀數（如從 30 改成 20）
- 使用其他 GIF 壓縮工具後處理

### Q: 可以批次處理很多檔案嗎？
A: 可以！只要把所有 GIF 放在同一目錄，`run.bat` 會自動處理所有檔案

### Q: 輸出檔名可以自訂嗎？
A: 目前輸出檔名格式固定為 `原檔名_幀數f.gif`，但可以自訂輸出資料夾

### Q: 支援哪些 GIF 格式？
A: 支援所有標準 GIF 格式，包括透明背景的 GIF

## 技術細節

- **幀率計算**：使用 `fps=目標幀數/原始時長` 來維持動畫時長
- **調色盤**：為每個 GIF 生成專屬調色盤，保留透明度
- **抖動演算法**：使用 `sierra2_4a` 抖動提升畫質
